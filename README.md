# 秦味 QINWEI — 擀面皮跨境电商演示网站（中英双语版）

> 毕业设计项目：以「宝鸡擀面皮」为主打产品的跨境电商品牌官网。
> 纯 HTML + CSS + 原生 JS，零依赖、零外链资源，完全离线可用，内置中 / EN 双语切换。

## 一、怎么打开

直接**双击 `index.html`** 即可在浏览器中打开（推荐 Chrome / Edge）。没有任何服务器依赖，换一台电脑也能直接打开。

## 二、怎么发给别人（拿到"点一下就进"的链接）

**方法 A：Netlify Drop（最快，30 秒，无需注册）**
1. 浏览器打开 `netlify.com/drop`
2. 把整个 `qinwei-mall` 文件夹拖进网页
3. 自动生成一个链接（形如 `https://xxx.netlify.app`），发给别人点开就能访问

**方法 B：GitHub Pages（永久链接，需要 GitHub 账号）**
1. 把文件夹推到一个 GitHub 仓库
2. 仓库 → Settings → Pages → 选 main 分支 → Save
3. 得到 `https://你的用户名.github.io/仓库名/` 链接

**方法 C：直接发文件** — 整个文件夹压成 zip 发微信 / QQ / 邮件，对方解压后双击 `index.html`。

## 五、想改品牌名 / 价格 / 商品 / 翻译？

全部集中在 `app.js`：

- `I18N`：全站界面文案（中文在 `zh:` 块，英文在 `en:` 块）
- `PRODUCTS`：商品名称、价格、口味、规格、描述、照片路径
- `REVIEWS` / `FAQS`：评价与常见问题（双语）
- `GALLERY`：首页实拍图鉴的照片墙
- 汇率换算写死为 7.2，在 `dInfoHTML` 函数里（搜索 `7.2`）
